# GameName v3

GameName is a character name generator for 64-bit Windows 10 and 11. Gurth wrote version 1, Tobias Diekershoff ported version 2, and NightLife built the version 3 Windows update.

Choose one of the 36 bundled lists or open your own `.nam` file. Select the name options, enter a count from 1 to 100, and click **Generate**. **Copy** puts the results on the clipboard. The **Generate** menu also has Random Name and Scrabble Name options.

The bundled lists include separate American, British, Australian, and New Zealand English lists. Chinese names use Mandarin romanization with the surname first.

This page documents GameName v3. The Windows build is currently distributed privately.
